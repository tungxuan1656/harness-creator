# Security Policy

## Supported versions

This repository has no published release or support matrix yet. Security fixes
should be evaluated against the current repository revision and the affected
skill or generated template.

## Reporting a vulnerability

Please do not disclose an unpatched vulnerability in a public issue. Report it
privately to [tungxuan.work10@gmail.com](mailto:tungxuan.work10@gmail.com).

Include the affected path, a concise description, reproduction steps when safe,
impact, and any suggested mitigation. Do not include credentials, private user
data, or other secrets in a report.

Maintainers will acknowledge the report when practical, investigate its impact,
and coordinate a fix or mitigation. Please allow reasonable time for a fix
before making details public.
